モデルコンバーター

さまざまなモデル形式のファイルを .pmx ファイルに変換して出力できます。

サポートされる変換方向：
FBX／unitypackage → PMX
VRM（0.x／1.0）→PMX
PMX → VRM（0.x / 1.0）
uemodel → PMX
PMX → uemodel
psk / pskx → PMX 
PMX →FBX
PMX → psk / pskx
XPS → PMX

macOS、Linux バージョンが必要な場合は、こちらからダウンロードしてください。
https://github.com/SaraKale/Model-To-PMX/releases

使用方法：
1. ダブルクリックしてModelConvert.exeを実行。
2. ファイルをドラッグしてここにドロップするか、ドラッグ＆ドロップエリアをクリックしてファイルを選択してください。
3.「タスク」ドロップダウンボックスでは変換方向を手動で指定でき、デフォルトでは拡張子により自動判断される。
4.変換結果とログは左下にあり、モデルプレビューは右欄の全列です。

問題関連：
－変換後のモデルの端に黒い線がある：本ツールはデフォルトで出力するPMXでMMD輪郭線をオフにします。
 まだ黒い枠が見える場合は、MMD/PMXEditorで全てのマテリアルを選択し、輪郭線がオフになっていることを確認して、「両面描画」にチェックを入れてください。
－透かし加工が残る場合：「材質強製両面」をチェックしてください。

既知の制限：
－FBX形式：バイナリFBX 7.xのみサポート、ASCII FBXはサポートしていない。
－貼り付け画像フォーマット：DDS／KTX2／WebPはスキップされます（材質が単色に劣化）。
－物理：PMX剛体/関節 ↔ VRM SpringBoneは相互に変換できません。
－材質エフェクト：.sph .spa .toonテクスチャはVRMで保持されません。
－ボーン名：FBX変換では英語のボーン名（Hips、Spine…）を保持するが、そのままではMMDの既存モーション（.vmd）にマッチしないため、PMXEditorで一括して日本語標準名に変更する必要がある。私が作成したPEのボーン整理プラグインをご利用いただけます。詳細は以下をご参照ください：
https://www.bilibili.com/video/BV1MfYX6JEhE/
https://studio.youtube.com/video/zZj-I4YgIDY/edit
https://www.nicovideo.jp/watch/sm46811122
－表情：ソースモデルにBlendShape/morphがない場合、PMX表情も0で、手作業で作成する必要がある。

アイコンの設計とテスト：
沙拉酱、小桃子
